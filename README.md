# Simplilearn × Lyzr — AI SDR Outreach Assistant

Workshop resources for participants: the use case, the knowledge base document,
the build prompt, the Gmail iteration prompt, and the coupon code.

**Live site:** https://suyash-lyzr.github.io/simplilearn-ai-sdr-resources/

## Contents

| File | What it is |
| --- | --- |
| `index.html` | The whole site — a single static page, no build step |
| `sage.css` | Sage design-system tokens (light + dark CSS variables) |
| `assets/Lyzr_Company_KB.docx` | The knowledge base participants upload into the app |
| `assets/coupon-walkthrough.mp4` | Screen recording: applying the coupon |
| `assets/agent-orchestration.png` | The multi-agent graph as it looks in Lyzr Studio |

## Running locally

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```
